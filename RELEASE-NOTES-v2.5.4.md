# MoneyCove v2.5.4

Final iPhone transaction-sheet and account polish.

- Makes Add/Edit Transaction a true full-screen, internally scrollable sheet on phones, sized to the live visual viewport so the Expense/Income switch and Amount field always remain reachable on iPhone.
- Tracks iOS visual-viewport changes while the keyboard opens/closes and restores the underlying page cleanly.
- Adds a Display name control in Settings. The chosen name is saved to the signed-in account and used in greetings, account UI and generated reports.
- Redesigns Export transactions in Settings with dedicated CSV and premium PDF options.
- Premium PDF export uses the polished MoneyCove Transaction Statement and remains a Pro feature, preserving the existing Free/Pro plan split.
